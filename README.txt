# Härteliste Scanner

Enthält deine eingelesene Liste mit 176 Teilen.

## Nutzung auf dem iPhone
1. Den kompletten Ordner auf einen HTTPS-Webspace laden, z. B. GitHub Pages, Netlify oder euren internen Webserver mit HTTPS.
2. `index.html` auf dem iPhone in Safari öffnen.
3. „Scanner starten“ drücken und den Barcode scannen.
4. Treffer werden automatisch abgehakt und lokal auf dem Gerät gespeichert.
5. Über „CSV exportieren“ bekommst du eine Liste mit Status `vor Ort` / `fehlt`.

Wichtig: Kamera im iPhone-Browser funktioniert normalerweise nur über HTTPS. Direkt als lokale Datei aus der Dateien-App ist unzuverlässig bzw. meistens blockiert.

## Funktionen
- Barcode-Scan über Kamera
- Manuelle Eingabe als Reserve
- Abgleich gegen laufende Nummer
- Anzeige Gesamt / Vor Ort / Fehlt
- Suche und Filter
- Lokale Speicherung im Browser
- CSV-Export
